# Tran Thi Lam - WordPress Developer CV

A personal portfolio / CV website built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Features

- Responsive dark-themed design matching the reference layout
- Smooth scroll navigation with fixed navbar
- Hero section with profile photo frame and vertical text accent
- About Me, Technical Skills, Soft Skills, and Languages cards
- Experience timeline with interactive dot indicators
- Featured projects grid with hover effects
- Education, Tools, Contact, and Let's Connect footer cards
- Scroll-to-top button

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

The site will be available at `http://localhost:5173`.

### Build for production

```bash
npm run build
```

The production files will be generated in the `dist/` folder.
